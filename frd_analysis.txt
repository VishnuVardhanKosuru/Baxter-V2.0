[P053] 8. Non-Functional Attributes
[P054] 8.1 Security
[P055] All traffic encrypted in transit via TLS 1.3; data at rest encrypted with AES-256 (RDS and S3).
[P056] PCI-DSS SAQ-A compliance maintained by tokenizing all card data via Stripe.js ΓÇö no raw card data touches ShopSphere servers.
[P057] OWASP Top 10 mitigations enforced: parameterized queries, input sanitization, CSRF tokens, strict Content-Security-Policy headers.
[P058] AWS WAF and rate limiting (100 requests/min per IP on auth endpoints) to mitigate brute-force and credential-stuffing attacks.
[P059] JWT access tokens expire after 15 minutes; refresh tokens are HttpOnly, Secure, SameSite=Strict cookies.
[P060] 8.2 Usability
[P061] WCAG 2.1 Level AA conformance across the storefront, including keyboard navigation and screen-reader labeling.
[P062] Mobile-first responsive design validated on the latest two major versions of Chrome, Safari, Firefox, and Edge.
[P063] Checkout reduced to a maximum of two screens / three total clicks from cart to order confirmation.
[P064] 8.3 Reliability
[P065] Circuit breakers around all third-party integrations (Stripe, shipping, notifications) with graceful degradation ΓÇö e.g., checkout 
[P066] Automated failover for the primary PostgreSQL instance with a Recovery Time Objective (RTO) of 5 minutes and Recovery Point Object
[P067] 8.4 Scalability
[P068] Backend services containerized and deployed on Kubernetes (EKS) with horizontal pod autoscaling based on CPU and request-queue dep
[P069] PostgreSQL read replicas serve catalog and reporting queries; Redis Cluster handles session and cart caching to shed load from the
[P070] 8.5 Maintainability
[P071] CI/CD pipeline (GitHub Actions) with mandatory unit test coverage ΓëÑ 80% and automated linting/static analysis gating merges.
[P072] Modular service boundaries (Catalog, Cart, Order, Payment, Notification) enabling independent deployment.
[P073] Feature flags (LaunchDarkly) used for progressive rollout of checkout changes.
[P074] 8.6 Compliance
[P075] GDPR: supports right-to-access and right-to-erasure requests for EU customers within the mandated 30-day window.
[P076] CCPA: provides a "Do Not Sell My Personal Information" opt-out mechanism for California residents.
[P077] PCI-DSS v4.0: annual SAQ-A self-assessment maintained by the Security team.
[P078] 8.7 Auditability & Logging
[P079] Centralized structured logging via the ELK stack (Elasticsearch, Logstash, Kibana) with correlation IDs across services.
[P080] Immutable audit trail for all order and payment state transitions, retained for 1 year in cold storage.
[P081] Admin actions (inventory adjustments, refunds, coupon creation) logged with user identity, timestamp, and before/after values.
